# Reform Workshop

เครื่องมือช่วยวางแผนการทำ **Enhancement Stone และการ Reform ใน Ragnarok Online** คำนวณวัตถุดิบที่ต้องใช้ เปรียบเทียบต้นทุน และบอกขั้นตอนแลกของที่ควรทำตาม

## เปิดใช้งาน

เปิดเว็บได้ทันทีที่:

**[เข้าใช้งาน Reform Workshop](https://econds.github.io/ro-reform-preparation/)**

หรือดูซอร์สโค้ดได้ที่ [econDS/ro-reform-preparation](https://github.com/econDS/ro-reform-preparation)

## วิธีใช้แบบเร็ว

1. เลือกประเภทไอเท็มที่ต้องการคำนวณ: **Weapon, Armor หรือ Accessory**
2. เลือกระดับหินและใส่จำนวนเป้าหมายที่ต้องการทำ
3. ใส่จำนวนวัตถุดิบที่มีอยู่แล้ว เช่น Enhancement Stone, Ore, Shadowdecon และ Zelunium
4. ใส่ราคาของที่ต้องซื้อในตารางราคา
5. เลือกแผนต้นทุนที่ต้องการ แล้วดูสรุปว่า
   - ต้องใช้ของทั้งหมดเท่าไร
   - มีของอยู่แล้วเท่าไร
   - ต้องซื้อเพิ่มอะไรบ้าง
   - ต้องจ่ายค่าแลก NPC เท่าไร
   - ควรแลกของตามลำดับใด
6. ทำตามรายการแลกในหัวข้อขั้นตอนแลก หรือคลิกชื่อไอเท็ม/คำสั่ง \`/navi\` เพื่อคัดลอกไปใช้ในเกม

## โหมดคำนวณ

- **ต้นทุนต่ำสุด** ใช้ของที่มีอยู่แล้วก่อน แล้วเปรียบเทียบการซื้อ Stone, ซื้อ Ore และการแลกจาก Shadowdecon เพื่อหายอดจ่ายที่ต่ำที่สุด
- **Shadowdecon** ใช้ Stone ที่มีอยู่แล้วและวัตถุดิบจาก Shadowdecon โดยไม่ซื้อ Enhancement Ore
- ระบบกัน Shadowdecon ที่ต้องใช้กับสูตร Reform ไว้ก่อน จึงไม่ถูกนำไปนับซ้ำกับสายผลิตหิน

## สิ่งที่ควรรู้ก่อนใช้ผลลัพธ์

- ราคาเริ่มต้นเป็นราคาอ้างอิง ไม่ใช่ราคาตลาดแบบเรียลไทม์ ควรแก้ให้ตรงกับราคาที่ซื้อได้จริงก่อนคำนวณ
- ราคาเว้นว่างหรือ \`0\` หมายถึง **ไม่ซื้อรายการนั้น** แต่ของที่มีอยู่แล้วจะยังถูกนำมาใช้
- ถ้าระบบหาเส้นทางซื้อให้ครบไม่ได้ จะแสดงสถานะรอราคาแทนยอดรวมที่ยังไม่ครบ
- การรวมแร่ใช้ Rough Shadowdecon **20 ชิ้น → Shadowdecon 1 ก้อน** และไม่มีค่าแลกตามเงื่อนไขที่ใช้ในเว็บ
- ระบบไม่รวมวัตถุดิบเฉพาะไอเท็ม เช่น Gray Shard, Ghost Chill, Death Rune หรือ Reform Stone รวมถึงเงื่อนไขระดับตีบวก ควรตรวจสอบจากตารางของเซิร์ฟเวอร์ก่อนทำจริง
- ผลลัพธ์เป็นแผนคำนวณเท่านั้น ไม่ได้หักของในเกมและไม่สามารถทำรายการแลกแทนผู้ใช้

## ข้อมูลและความเป็นส่วนตัว

- เว็บไม่มี backend และไม่ส่งข้อมูลไปที่เซิร์ฟเวอร์
- จำนวนของที่มี ราคา และเป้าหมายถูกเก็บไว้ใน \`localStorage\` ของเบราว์เซอร์เครื่องนั้น
- หากล้างข้อมูลเว็บไซต์หรือเปลี่ยนเบราว์เซอร์ ค่าที่บันทึกไว้อาจหาย
- ปุ่มคืนราคาเริ่มต้นจะรีเซ็ตเฉพาะราคาที่แก้ไข ไม่ล้างจำนวนของที่มี

## เปิดรันบนเครื่องตัวเอง

ต้องมี Node.js จากนั้นรัน:

\`\`\`bash
npm start
\`\`\`

แล้วเปิด [http://127.0.0.1:4173](http://127.0.0.1:4173)

ไม่ต้องติดตั้ง dependencies เพิ่ม และทดสอบสูตรด้วย:

\`\`\`bash
npm test
\`\`\`
