# Reform Workshop

เว็บภาษาไทยสำหรับคำนวณ Enhancement Stone ใน Ragnarok Online ตามสูตร [iRO Wiki — Item Reform](https://irowiki.org/wiki/Item_Reform#Materials) ตรวจสอบ 5 กันยายน 2026

## เปิดใช้งาน

เปิด `index.html` ได้โดยตรง หรือใช้ Node.js รัน `npm start` แล้วเปิด http://127.0.0.1:4173 เพื่อให้ local storage ทำงานบน origin ที่แน่นอน ไม่ต้องติดตั้ง dependencies

## ขึ้น GitHub Pages

1. นำ `index.html`, `styles.css`, `calculator.js`, `app.js` และ `.nojekyll` พร้อมโฟลเดอร์ `assets` ไว้ที่ root ของ repository
2. เปิด repository → Settings → Pages
3. เลือก Deploy from a branch → main → / (root) → Save
4. รอ GitHub Pages deploy แล้วใช้ URL ที่ GitHub แสดง

ทุก asset ใช้ relative path จึงรองรับทั้ง `username.github.io` และ `username.github.io/repository/` ไม่มี backend หรือ build step ฟอนต์ Google Fonts เป็น optional และมี system font สำรอง

## การคำนวณ

- รองรับ Weapon / Armor / Accessory และ Low / Medium / High / Supreme
- รองรับวัตถุดิบที่สูตร Reform ใช้ตรง ๆ นอกเหนือจากหิน คือ Shadowdecon และ Zelunium ใส่จำนวนในหัวข้อ 01 ตามแถวในตาราง RO GGT
- ลักษณนามเลือกตามรูปร่างไอเท็มจริงในเกม และคงที่ทุกที่ในเว็บ: Enhancement Stone เป็นอัญมณีเจียระไนใช้ `เม็ด`, Enhancement Ore เป็นผลึกดิบใช้ `ชิ้น`, Rough Shadowdecon เป็นผลึกแท่งเดี่ยวใช้ `แท่ง`, Shadowdecon เป็นกลุ่มผลึกใช้ `ก้อน`, Zelunium และ Rough Zelunium เป็นก้อนโลหะใช้ `ก้อน` (iRO DB ระบุ Zelunium ว่า "A metal with a golden glow" subtype Ore) · หัวข้อที่ครอบทุกไอเท็มพร้อมกันใช้ `หน่วย`
- Zelunium ไม่มีระดับและไม่มีสายอัปเกรด มีแค่ Zelunium กับ Rough Zelunium ใช้สูตร 20 ชิ้น → 1 ก้อน เหมือน Shadowdecon และไม่มีค่าธรรมเนียม
- ความต้องการของสูตร Reform ถูกกันไว้ก่อนสายหิน เพราะเลี่ยงไม่ได้ Shadowdecon ก้อนเดียวกันจึงไม่ถูกนับซ้ำสองทาง และเมื่อของที่มีถูกใช้หมดไปกับสูตร สายหินจะเปลี่ยนไปใช้ Enhancement Ore แทนโดยอัตโนมัติ
- การ์ดเปรียบเทียบสามทางเทียบเฉพาะค่า Enhancement Stone เพราะทุกทางต้องใช้ Shadowdecon / Zelunium ของสูตรเท่ากัน ค่าส่วนนั้นแสดงแยกในสรุปค่าใช้จ่ายและใต้การ์ดเปรียบเทียบ
- ไม่รองรับวัตถุดิบเฉพาะไอเท็ม เช่น Gray Shard, Ghost Chill, Death Rune, Reform Stone และเงื่อนไขระดับตีบวก ให้ดูจากตาราง RO GGT โดยตรง
- ราคาซื้อรองรับวัตถุดิบดรอป รวมถึง Weapon, Armor และ Accessory Enhancement Stone ที่มีข้อมูลตลาด
- โหมดต้นทุนต่ำสุดใช้ Stone ที่มีอยู่แล้ว แล้วเลือกผสม Low Ore, Medium Ore และ Shadowdecon เพื่อให้เงินจ่ายเพิ่มต่ำที่สุด
- โหมด Shadowdecon ใช้ Stone ที่มีอยู่แล้วและ Shadowdecon / Shadowdecon Ore โดยไม่ใช้ Enhancement Ore
- คำนวณด้วยจำนวนเต็ม รวมเศษ Ore ที่มีแล้วได้ เช่น มี 19 Ore จะซื้อเพิ่มเพียง 1 เพื่อรวมเป็น 1 Shadowdecon หากคุ้มกว่า
- ก้อนใหญ่ที่มีอยู่แล้วถูกใช้ก่อนรวมจาก Ore; ของที่มีอยู่แล้วคิดต้นทุนเพิ่มเป็นศูนย์ ไม่รวมมูลค่าขายต่อหรือต้นทุนเดิม
- ราคาเว้นว่างหรือ 0 = ยังไม่ระบุราคา ไม่ซื้อเพิ่ม แต่ใช้ของที่มีอยู่แล้วได้; หากไม่มีเส้นทางซื้อครบ จะแสดงรอราคาแทนยอดรวมที่ไม่ครบ ราคา 0 ที่เคยบันทึกไว้จะถูกอ่านเป็นช่องว่างเมื่อเปิดหน้าเว็บใหม่
- เป้าหมายสูงสุด 10,000 เม็ด จำนวนของที่มีสูงสุด 1,000,000,000 หน่วย ราคาสูงสุด 1,000,000,000,000 z ต่อชิ้น (JavaScript floating point; ราคาสูงมากอาจมีความคลาดเคลื่อนระดับเศษหน่วย)
- เก็บราคา จำนวนของที่มี และเป้าหมายใน browser local storage คีย์ `reform-workshop.v1` แยกตามประเภทหิน ไม่ส่งข้อมูลไป server และไม่หักของในเกมจริงเมื่อคำนวณ
- ปุ่มคืนราคาเริ่มต้นรีเซ็ตราคาที่แก้ทั้งหมดกลับเป็น Default ปัจจุบัน โดยไม่ล้างจำนวนของที่มี
- การ์ดเปรียบเทียบสามทางแสดง วิธีที่แนะนำ (ยอดเดียวกับสรุปค่าใช้จ่าย) เทียบกับแลกเองผ่าน Shadowdecon และซื้อหินจากตลาดเลย ทางที่ถูกที่สุดมีป้ายกำกับ พร้อมจำนวนที่มี จำนวนที่ต้องหาเพิ่ม และส่วนต่างราคา
- การรวมแร่ใช้ Rough Shadowdecon 20 ชิ้น ต่อ 1 ก้อน ไม่มีค่าแลก ตามเงื่อนไขผู้ใช้ ทำที่ NPC ในห้องอัปเกรดอาวุธ 7 เมือง: Satana (`/navi alberta_in 24/63`), Polinn Polath (`/navi prt_in 64/57`), Marik Meloy (`/navi morocc_in 64/37`), Jihu Jeyorr (`/navi payon 142/179`), Dimille Maar (`/navi yuno_in01 164/31`), Galan Gweniha (`/navi ein_in01 30/88`), Nemill Newton (`/navi lhz_in02 275/23`) ทุกพิกัดคัดลอกได้จากหน้าเว็บ
- Rough Shadowdecon ในภาพผู้ใช้ถือเป็น Shadowdecon Ore
- ราคาตัวอย่าง Weapon Enhancement Ore: Low Grade 8,000 z และ Medium Grade 18,890 z; Weapon Enhancement Stone: Low Grade 33,750 z, Medium Grade 110,000 z, High Grade 358,888 z และ Supreme Grade 1,290,000 z; Armor Enhancement Ore: Low Grade 8,889 z และ Medium Grade 23,000 z; Armor Enhancement Stone: Low Grade 39,990 z, Medium Grade 127,000 z, High Grade 409,999 z และ Supreme Grade 1,600,000 z; Accessory Enhancement Ore: Low Grade 7,800 z และ Medium Grade 21,990 z; Accessory Enhancement Stone: Low Grade 34,990 z, Medium Grade 117,500 z, High Grade 399,000 z และ Supreme Grade 1,500,000 z; Shadowdecon 19,000 z และ Rough Shadowdecon 950 z มาจากภาพผู้ใช้ ไม่ใช่ราคาสดและไม่จำกัดตาม stock ของร้านในภาพ
- อัปเดตราคาเริ่มต้น Weapon และ Armor Low/Medium Ore, Weapon Stone ทุกระดับ, Armor Stone ทุกระดับ, Accessory Low/Medium Ore และ Accessory Stone ทุกระดับ ให้ข้อมูลเดิมที่ยังไม่ระบุราคาหนึ่งครั้ง โดยคงราคาที่ใส่ไว้แล้ว และยังล้างราคาเองได้ภายหลัง
- ราคาเริ่มต้น Rough Shadowdecon เดิม 1,500 z จะอัปเดตเป็น 950 z หนึ่งครั้ง ส่วนค่าที่ตั้งเป็นราคาอื่นจะคงไว้
- โหมดต้นทุนต่ำสุดเปรียบเทียบราคา Stone ที่ใส่ไว้กับการแลกจาก Ore หรือ Shadowdecon ทุกระดับ ส่วนโหมด Shadowdecon จะไม่ซื้อ Stone โดยตรง
- แต่ละขั้นระบุเมนูของ Ore Researcher ที่ต้องเลือก ทั้งเลขข้อและคำในเกมภาษาไทย (ข้อ 1 `สกัดแร่` = แร่ 5 → หิน 1, ข้อ 2 `แลกเปลี่ยนแร่ระดับสูง` = หิน 3 → หินระดับถัดไป 1, ข้อ 3 `ซื้อแร่เพิ่มเติม` = Shadowdecon 1 → Low Stone 1 มีเฉพาะระดับ Low) พร้อมชื่ออังกฤษกำกับ และมีผังบทสนทนาทั้ง 2 ชั้นพร้อมเลขข้อ กับตารางสรุปทั้ง 3 เมนู ในหัวข้อที่พับไว้ เลขข้อนับตามลำดับบรรทัดจากบนลงล่างในภาพผู้ใช้
- ขั้นตอนแลกเรียงตามลำดับที่ทำได้จริง (ผู้ผลิตมาก่อนผู้ใช้) ใช้รูปแบบ `แลก INPUT → OUTPUT` ทุกขั้น และแยกที่มาของวัตถุดิบเป็น มีอยู่แล้ว / ซื้อเพิ่ม / จากขั้นก่อนหน้า เมื่อมาจากหลายทาง ขั้นที่ไม่มีค่าแลกจะแสดง "ไม่มีค่าแลก" แทนยอด 0 z
- ราคา 0 หรือเว้นว่างแสดงเป็นสถานะ "ไม่ซื้อ" บนช่องนั้น ตัวเลขที่พิมพ์ไม่หายไปเอง และการแก้ราคากลางช่องไม่ทำให้เคอร์เซอร์กระโดดไปท้ายช่อง
- ค่าแลกแสดงเป็น "N ชุด × ค่าแลก" เพราะหน้าต่างแลกใส่จำนวนได้ทีเดียว ไม่ต้องกดทีละครั้ง
- ปุ่มล้างจำนวนของที่มี มีปุ่มเลิกทำหนึ่งขั้น
- หน้าจอแคบมีแถบยอดรวมติดขอบล่างเมื่อเลื่อนพ้นการ์ดสรุป และเมนูแสดงชื่อหัวข้อแทนไอคอนล้วน
- รองรับธีมมืดตาม `prefers-color-scheme` ของระบบ
- ตารางราคาแบ่งเป็น SHADOWDECON (ใช้ร่วมทุกประเภท) → ประเภทที่กำลังคำนวณ → ประเภทอื่นที่พับเก็บไว้ สลับกลุ่มตามปุ่ม Weapon / Armor / Accessory และแถวที่แผนต้องซื้อจริงมีป้าย "แผนนี้ซื้อ N" ราคาของประเภทอื่นยังถูกบันทึกไว้ครบ
- การ์ด Shadowdecon บอกที่มาของทุกก้อน (ใช้ของที่มี / รวมจาก Rough / ซื้อใหม่) และบอกเหตุผลเมื่อไม่ต้องเตรียมเพิ่ม เช่น ของที่มีพอแล้วและเก็บ Rough ไว้ได้

## ตัวอย่างตรวจสอบ

Accessory Supreme 100 เม็ด เริ่มจากศูนย์และใช้ Shadowdecon:

| ขั้น | จำนวนผลผลิต | ค่า NPC รวม |
|---|---:|---:|
| Shadowdecon → Low | 2,700 | 54,000,000 z |
| Low → Medium | 900 | 9,000,000 z |
| Medium → High | 300 | 6,000,000 z |
| High → Supreme | 100 | 5,000,000 z |

ค่า NPC 74,000,000 z + Shadowdecon 2,700 × 19,000 z = **125,300,000 z**

เมื่อใช้โหมดต้นทุนต่ำสุดกับราคาตัวอย่างปัจจุบัน ระบบจะซื้อ Accessory Low Stone 2,700 เม็ด × 34,990 z แล้วแลกต่อเป็น Medium / High / Supreme ค่าไอเท็ม 94,473,000 z + ค่า NPC 20,000,000 z = **114,473,000 z**

## คัดลอกชื่อไอเท็ม
